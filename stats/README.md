## ระบบหลังบ้าน (Supabase โปรเจกต์ Lotto888)

- ตาราง `thai_draws`, `hanoi_draws`, `hanoi_sp_draws`, `hanoi_vip_draws`, `lao_draws`, `fetch_log` — เว็บอ่านได้อย่างเดียว (เขียน/ลบไม่ได้)
- Edge Function `fetch-results` (รุ่นที่ใช้งานอยู่ v7 แก้จาก session อื่น — โค้ดอยู่บน Supabase ไม่ได้รวมในชุดนี้ กันของเก่าไปทับ) ดึงผลแล้วเพิ่มงวดใหม่ · งวดเดิมที่เลขต่างจะ **ไม่ทับ** แต่บันทึก `conflict` ใน `fetch_log`
- `pg_cron` ดึงอัตโนมัติทุก 5–10 นาที ช่วง **15:00–03:50 น.** (ดึงเฉพาะหวยที่ถึงเวลาออกและยังไม่มีผลวันนั้น)
- ดูประวัติการดึง: Supabase → Table Editor → `fetch_log`
